# 🌐 Introdução ao HTML

Primeiro exercício prático de desenvolvimento web, criado para praticar a estrutura básica de uma página HTML.

## 📌 Sobre o projeto

O projeto consiste em uma página simples contendo uma mensagem de "Olá, Mundo!", servindo como primeiro contato com a criação de páginas utilizando HTML.

## 🛠️ Tecnologias

- HTML5

## 🎯 Objetivo

Praticar a estrutura básica de um documento HTML e compreender o funcionamento dos principais elementos de uma página web.

## 🚀 Como executar

Abra o arquivo HTML diretamente em um navegador.
